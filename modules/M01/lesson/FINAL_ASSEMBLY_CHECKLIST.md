## 5. 剪辑原则

- 一个画面只承担一个观察任务；
- JSON 与代码出现时，旁白先说明要找什么，再高亮；
- 终端命令完整出现一次即可，后续可以使用局部放大；
- v0 的错误结果必须保留足够时间让观众读懂；
- `NEEDS_CLARIFICATION` 的非零退出不剪成程序崩溃；
- `READY` 出现时，不使用庆祝动画、完成音效或“任务成功”文案；
- 互动课件用于过渡和总结，不替代真实文件与终端；
- 不使用机器人、大脑、数据流隧道等装饰画面填充空白；
- 没有信息需要展示时，保留简单标题或让真人画面停留。

## 6. 音频验收

- [ ] 正式旁白完整覆盖主课；
- [ ] 真人和旁白的响度接近；
- [ ] 无明显底噪、齿音、削波和房间混响；
- [ ] 文件名、JSON 字段和英文状态读法统一；

- [ ] 背景音乐如使用，不能遮盖代码和状态讲解；
- [ ] 不用音效制造“READY 等于完成”的感受。

- [ ] SRT 与最终音频重新对齐；

- [ ] 中文标点统一；

- [ ] 不在字幕中自行增加讲师没有说的结论。

- [ ] 电脑全屏 1080p；
- [ ] 手机横屏；

检查：

- JSON 字号；
- 终端输出；
