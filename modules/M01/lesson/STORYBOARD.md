# M01 分镜与剪辑计划

## 总体视觉

画面以真实工作台为主：文件、编辑器、终端、状态、JSON 和对比。

真人镜头只在开场、关键判断和结尾出现。缺少真人素材时，可以使用课程标题卡和旁白替代，不影响理解。

## 真人素材清单

### H01｜开场

- 时长：15–20 秒；
- 景别：中景；
- 台词：见讲师稿；
- 作用：建立人与课程的关系；
- 可替代：标题卡 + 旁白。

### H02｜作业说明

- 时长：15–20 秒；
- 景别：中近景；
- 作用：强调不要上传真实内部内容；
- 可替代：安全提示页 + 旁白。

### H03｜收束

- 时长：15–20 秒；
- 景别：近景；
- 作用：回顾本集产出并进入 M02；
- 可替代：四文件结束卡。

## 屏幕录制清单

1. 打开 `request.txt`；
2. 查看任务卡草稿；
3. 显示文件树；
4. 运行 v0；
5. 查看 v0 任务卡；
6. 打开静默默认值代码；
7. 打开 v1 必填字段；
8. 运行无 confirmation 的 v1；
9. 查看 `questions.md`；
10. 查看 NEEDS_CLARIFICATION 的 `run_record.json`；
11. 查看 `confirmation.json`；
12. 再次运行 v1；
13. 查看 READY 任务卡；
14. 运行单元测试。

## 字幕和屏幕文字

- 中文主字幕每行建议不超过 18 个汉字；
- 专业英文第一次出现时保留英文并给中文解释；
- 路径在画面中显示相对路径；
- 不展示个人用户名和绝对路径；
- JSON 中所有姓名、日期和文件均标注为 DEMO。

## 声音

- 开场和结尾可使用极轻背景音乐；
- 运行、状态变化使用低存在感提示音；
- 错误不使用警报式音效；
- 重点依靠停顿和画面变化，不靠音效制造紧张。

## 导出

- 主成片：16:9，4K 或 1080p；
- 字幕：烧录版 + 独立 SRT；
- 屏幕录制：优先 60fps，最终可导出 30fps；
- 代码字体：保证手机横屏仍可读；
- 课程图示保留 SVG 原文件。
