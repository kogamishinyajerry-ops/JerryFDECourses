# M01 互动课件

## 用途

这个静态页面同时用于：

- Main Lesson 屏幕录制；
- 课堂现场演示；
- 学员课后回看；
- 课程视觉和状态语言的基准实现。

页面不调用服务器、不访问网络、不读取真实文件。

## 运行

直接双击：

```text
index.html
```

也可以从仓库根目录启动一个静态服务器：

```bash
python -m http.server 8000
```

打开：

```text
http://localhost:8000/modules/M01/site/
```

## 互动步骤

1. 打开请求；
2. 人工提取；
3. 运行 v0；
4. 检查 v0；
5. 构建 v1；
6. 人工确认；
7. READY 与证据；
8. 概念与迁移。

使用左右方向键或底部按钮切换。

## 录屏方式

- 关闭浏览器标签栏以外的个人信息；
- 画面宽度建议 1440 px 以上；
- 左侧导航保持可见；
- 每个步骤单独录制；
- “运行 v0”“运行 v1”“应用人工确认”应在旁白对应位置点击；
- READY 页面停留至少 5 秒；
- 不把页面当作真实生产系统演示。

## 设计边界

- 无外部字体和前端依赖；
- 无真实模型；
- 无真实工程数据；
- 无网络请求；
- 无本地存储；
- 所有姓名和日期为 DEMO；
- 所有状态只用于课程说明。
